* ##### SOLID
	- Single responsibility - объект, метод должны заниматься только одним своим делом, в противоположность антипатерну God-object
	- Open closed principle - для добавления новых функций не должно требоваться изменять существующий код
	- Liskov substitution - использовать базовый класс не зная о реализации наследника
	- Interface segregation principle - не раздувать интерфейсы
	- Dependency inversion principle - вначале интерфейсы, потом реализация, но не наоборот
- ##### Паттерны Делятся на 3 типа
	- порождающие (пример: фабрика)
	- структурные (пример: декоратор)
	- поведенческие (пример: цепочка обязанностей)
* #####  Принципы 
	* KISS, 
	* DRY, 
	* YAGNI, 
	* BDUF ### Big Design Up Front, 
	* SOLID, 
	* APO  ### Avoid Premature Optimization
	* бритва Оккама

1. Название датчика состоит из букв R, S, M. Название считается правильным если в нем символ R находится раньше чем символ М. Определите является ли название s правильным.

	- Пример:

2. Оля подключена к мобильному оператору «Мобайл». Абонентская плата Оли составляет X1 рублей в месяц. За эту стоимость Оля получает X2 мегабайт интернет-трафика. Если Оля выйдет за лимит трафика, то каждый следующий мегабайт будет стоить ей X3 рубля. Оля планирует потратить X4 мегабайт интернет-трафика в следующий месяц. Помогите ей сосчитать, во сколько рублей ей обойдется интернет.
	Формат входных данных
	Вводится 4 целых положительных числа  — стоимость тарифа Оли, размер тарифа Оли, стоимость каждого лишнего мегабайта, размер интернет-трафика Оли в следующем месяце. Числа во входном файле разделены пробелами.
	Формат выходных данных
	Выведите одно натуральное число — суммарные расходы Оли на интернет.
	- Пример: 
		- Вход 500 1000 5 1004  Вывод 520
		- Вход 500 1000 5 104  Вывод 500
	Замечание
	В первом примере Оля сначала оплатит пакет интернета, после чего потратит на  4 мегабайта больше, чем разрешено по тарифу. Следовательно, за 4 мегабайта она заплатит отдельно 20 рублей, получившаяся стоимость 520  рублей.
	Во втором примере Оля укладывается в тарифный план, поэтому платит только за него.
3. В ИТ отделе компании Теко решили провести соревнование юных хакеров CaptureTheFlag. Коля настроил на серверах логи, фиксирует данные о подключении к серверам. 
	Каждая команда делает несколько запросов к серверам, и каждый запрос имеет следующие параметры:
	- Имя команды (строка)
	- Время запроса (в формате HH:mm:ss)
	- IP Сервера (строка)
	- Результат (строка), который может быть одним из следующих:
	  - ACCESSED (доступ разрешен)
	  - DENIED (доступ запрещен)
	  - FORBIDEN (доступ запрещен)
	Вам необходимо разработать программу, которая будет обрабатывать логи подключения команд к серверам и вычислять результаты на основе времени доступа и статуса запросов.
	Программа должна принимать время, после которого запросы считаются "запоздалыми", и общее количество запросов. Затем программа должна обрабатывать каждый запрос и вычислять следующие результаты для каждой команды:
	1. Количество серверов, к которым команда получила доступ (т.е. количество уникальных серверов с результатом ACCESSED).
	2. Штрафное время (в минутах):
	   - Если запрос был сделан до заданного времени, штрафа нет.
	   - Если запрос был сделан после заданного времени, то добавляется разница в минутах между временем запроса и заданным временем.
	   - За каждый запрос с результатом DENIED или FORBIDEN, сделанный к серверу, к которому команда уже получила доступ, добавляется штраф в 20 минут.
	#### Выходные данные
	Для каждой команды необходимо вывести:
	- Позицию команды (1, 2, 3 и т.д. по убыванию штрафного времени).
	- Имя команды.
	- Количество уникальных серверов, к которым команда получила доступ.
	- Общее штрафное время.
	#### Формат ввода
	1. Время (в формате HH:mm:ss).
	2. Количество запросов.
	3. Для каждого запроса:
	   - Имя команды
	   - Время запроса (в формате HH:mm:ss)
	   - Сервер
	   - Результат
	#### Пример ввода
	10:00:00
	5
	TeamA 09:30:00 Server1 ACCESSED
	TeamB 10:05:00 Server1 ACCESSED
	TeamA 09:45:00 Server2 DENIED
	TeamB 09:50:00 Server1 FORBIDEN
	TeamA 10:15:00 Server1 ACCESSED
	#### Пример вывода
	1. TeamA 2 0
	2. TeamB 1 20
4. Однажды Николай решил, что на протяжении следующих N дней он будет покупать по три датчика. Там, где живет Николай, существует только один магазин датчиков, зато в нем широкий ассортимент. Для любого i в магазине есть ровно один датчик, стоящий 2^i  рублей. К тому же в магазин ежедневно довозят цветы, которые были выкуплены. 
	В i-ый день в Николая есть a_i рублей, которые он готов потратить на датчики. Николай хочет купить как можно более дорогие датчики. Для каждого из N дней определите, за какую стоимость Николай купить датчики, или сообщите, что на его деньги невозможно купить три датчика
	- Вход: N, a_i 
	- Выход: Количество рублей потраченных в каждый день
	- Пример: 
		- вход 3, 15, 67, 5. 
		- выход 14 (2 + 4 + 8), 67 (1+ 2 + 64), -1 (не достаточно)
